Bulk export / import (file)

Dump this indexer's entire chat store (handshakes, DMs, payments, self-stash, groups) to one file, or restore from a file another indexer exported — byte-for-byte, no re-parsing. The simplest way to move all history between indexers.

Import chat history (by address)

Backfill a wallet's direct-message (DM) history from the block explorer into this indexer — for messages older than the node's pruning window. Import your own address and your contacts' addresses to rebuild both sides of a conversation. (Contextual messages only; handshakes/payments are a follow-up.)

Personal indexing

Index only your own chats. Add your KaChat address(es) and/or group ids below and the chat indexer stores only data involving you — everyone else's traffic is skipped. Leave both empty to index everything (public-indexer default). Saving restarts the chat indexer so the change takes effect.

Group ids are per-(group, member) blinded ids that KaChat computes — listing yours reliably captures your messages in those groups (plus anything you send). Capturing every member's messages in a group needs roster knowledge the indexer is designed not to have. After enabling, use Export / Import → Import chat history to backfill your DM history.
