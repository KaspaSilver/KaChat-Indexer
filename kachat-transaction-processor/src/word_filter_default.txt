# Default word filter (docs/WORD_FILTER.md): public chats and KaPosts (posts, replies, quotes,
# polls, edits, profile broadcasts). A message containing any of these is not stored, so no app
# using this indexer shows it. The processor copies this list into `kachat_word_filter` once, on
# first start; after that the panel's list is the one used.
#
# Matching:
#   - Not case-sensitive; accents are dropped (é -> e).
#   - Common letter swaps are undone first: 0->o 1->i 3->e 4->a 5->s 7->t @->a $->s.
#   - Stretched letters are undone: "fuuuck" and "shiiit" match.
#   - Whole words only: "ass" does not match "class" or "assistant".
#   - A trailing * matches any ending: "fuck*" matches fuck, fucks, fucking, fucker.
#   - Two or more words match as a phrase.
